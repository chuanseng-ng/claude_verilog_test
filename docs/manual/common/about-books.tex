The project has four books. Each book is a LaTeX document that builds to a PDF.
\begin{description}
  \item[Design Specification (DS)] States what the design must do. It holds the rules that a test can fail.
  \item[Technical Manual (TM)] Describes how the design and the flows work. It holds the block descriptions and the generated tables of ports and parameters.
  \item[User Manual (UM)] Shows how to use the project. It holds the tasks, the commands and the writing rules.
  \item[Changes record (CR)] Keeps the history. It does not describe the current state.
\end{description}
