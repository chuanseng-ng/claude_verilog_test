# One entry per line:   module | kind | regex | category | justification
#
#   module        RTL module name (parameter specialisations are folded into the base name)
#   kind          line   -> line + branch points, matched against "L<line>" or "L<line> <arm>"
#                 toggle -> toggle points, matched against "<signal>[<bit>]:<from>-><to>"
#                 any    -> either
#   regex         Python re.search pattern; ' | ' (spaces around the bar) separates fields, so a
#                 regex may contain a bare alternation bar such as ^L(20|31)$
#   category      b = unreachable BY DESIGN (tie-off, EN_*=0 generate arm, elaboration guard).
#                 Test gaps (a) and bugs (c) are beads, never waivers.
#   justification mandatory; say WHY the point cannot be reached, with a file:line reference.
#
# A waiver removes only UNCOVERED points from the denominator; the report keeps the raw % beside
# the adjusted one and flags a waiver that matches nothing as stale.  No pragma edits to RTL.
