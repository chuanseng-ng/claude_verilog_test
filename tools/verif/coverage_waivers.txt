# Coverage waivers for tools/verif/coverage_report.py (GH #216, bead nkj7; anchors: bead xlc4).
#
# One entry per line:   module | kind | pattern | category | justification
#
#   module        RTL module name (parameter specialisations are folded into the base name)
#   kind          line   -> line + branch points; the pattern is a SOURCE ANCHOR (below)
#                 toggle -> toggle points, regex matched against "<signal>[<bit>]:<from>-><to>"
#                 any    -> either, regex over the point label (never a line number)
#   pattern       line:   one or more anchors  @"<text of the waived source line>"  separated by
#                         spaces.  The text is compared after dropping // and /* */ comments and
#                         collapsing whitespace, so re-wording a comment or re-aligning the line
#                         keeps the waiver, while any edit to the code makes it STALE.  An anchor
#                         must match exactly one line of the file that declares <module>; when the
#                         same text occurs N times add #k/N (k-th of N identical lines, e.g.
#                         @"default: ;"#2/3).  N is checked: if the count of identical lines changes
#                         the waiver goes stale rather than re-pointing.  A bare anchor that matches
#                         several lines is an ERROR.  An anchor waives every line and branch point
#                         on its line.  Escape " and \ inside the text as \" and \\.
#                 toggle/any: Python re.search pattern; ' | ' (spaces around the bar) separates
#                         fields, so a regex may contain a bare alternation bar.
#   category      b = unreachable BY DESIGN (tie-off, EN_*=0 generate arm, elaboration guard).
#                 Test gaps (a) and bugs (c) are beads, never waivers.
#   justification mandatory; say WHY the point cannot be reached, with a file:line reference.
#                 (Line numbers in the prose are for the reader and are not checked.)
#
# A waiver removes only UNCOVERED points from the denominator; the report keeps the raw % beside
# the adjusted one.  No pragma edits to RTL.
#
# A stale anchor (the waived line was edited or removed, a module vanished, the count of identical
# lines changed) FAILS `coverage_report.py --gate`, and `coverage_report.py --check-waivers` (run by
# the QA job) fails it on every PR with no simulation.  To fix one, re-read the RTL, confirm the
# point is still unreachable by design, and update the anchor.  Old numeric entries can be
# converted with `coverage_report.py --migrate-waivers <file>`.
